# Personal Technical Blog

An Astro-based personal technical blog for software development notes, tools, systems, and ongoing learning.

## Local development

```powershell
pnpm install
pnpm dev
```

The default local URL is `http://localhost:4321/`.

## Build

```powershell
pnpm build
```
